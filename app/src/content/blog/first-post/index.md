ブログを開設しました。

## なぜブログを作ったのか

理由はいくつかありますが、一番大きいのは自分のための日記として残したいという気持ちです。

普段アジャイルで自社プロダクトを開発していて、日々考えることがいっぱいあります。

そんな中でいいことを思いついたり、考えたりするのですが、それがその場で揮発してしまうのが勿体無い。

そういう感覚がありました。

## なぜAWSで自作しているのか

このサイトは AWS CDK で管理しています。

理由は AWS を自在に触れる人になりたかったから。

仕事でも AWS を使っていますが、インフラを自信を持って触れる人が少ない状態です。

自分も触れるようになりたいと思っていたものの、本番環境を壊してしまう可能性があるため、何か変更するたびに詳しい人に相談しないと不安になる状態でした。

そこで自己責任で挑戦しやすい土俵を作ることにしました。

そしていろいろやってみて学ぶことにしました。

## なぜリポジトリを公開しているのか

このサイトを構築するのに使った全てのソースコードをパブリックに公開しています。

これは今回の取り組みにポートフォリオ的な側面も持たせたいと思ったからです。

パブリックにすることで、漏洩してもセキュリティ事故にならないようなソースコードを意識させられました。

`.env` や GitHub Actions Variables / Secrets の使い方についてとても考えさせられました。

## このブログで何を書いていくのか

まだ自分がどんなことを書いていくのか、はっきりとは見えていないのですが、以下のようなことを書いていきたいと思っています。

- 技術的な学び
- 日々の開発で悩んでいること、考えたこと、実践したこと

記事が貯まってきたとき、このブログを見た人が「ごぼうさんってこういう人なんだな」と理解できるような場所になればいいなと思っています。
